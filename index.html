시작하기 전에 — API 키 한 번만 넣기

이 사이트는 글을 만들 때 Claude를 부릅니다. 그 요금은 각자의 키로 청구되므로 본인 키가 필요합니다. 키는 이 브라우저에만 저장되고 어디로도 전송되지 않습니다.

키가 없으시면 console.anthropic.com 에서 계정을 만들고 API Keys 메뉴에서 발급받으세요. 글 한 편에 수십 원 수준입니다.

1. 왜배경·목적
2. 무엇을주제·자료
3. 어떻게구성·문체
4. 누구에게독자

왜 쓰는가

쓰는 이유를 분명히 하면 글의 방향과 시점이 뚜렷해집니다.

무엇을 쓰는가

무엇에 대해 쓰는지(소재)와 어떤 글로 쓰는지(유형)를 따로 고릅니다.

링크 안의 내용은 초안을 만든 뒤 대화창에서 열어 확인합니다. 지금 단계에서는 어떤 자료를 참고할지 목록으로만 넘어갑니다.

글자로 된 파일은 내용을 바로 읽어 씁니다. 그 밖의 파일은 이름만 넘기고 초안을 만든 뒤 대화창에서 열어 봅니다.

어떻게 쓰는가

전개와 마무리, 길이와 말투를 정합니다.

누구에게 보내는가

독자를 좁힐수록 문장이 선명해집니다. 모두에게 쓴 글은 결국 아무에게도 닿지 않습니다. 같은 주제라도 독자가 달라지면 예시와 설명의 깊이가 완전히 달라집니다.

무엇을 바꿔 쓸까요

비워두면 지금 설정 그대로 다시 씁니다.

본문 초안

① 쓰기 탭에서 빈칸을 채운 뒤 초안 만들기를 누르세요.

자가 점검

고른 전개·마무리 방식에 맞는 기준으로만 검사합니다.

위 세 가지는 자가 점검과 별개로, 지금 본문을 각 기준에 맞춰 다시 손보는 기능입니다. 고친 문장은 본문에 굵게 표시됩니다.

올릴 매체

고른 매체마다 글자수와 해시태그 수를 따로 정할 수 있습니다.

발행하기

고른 매체 전체에 한 번에 나갑니다. 발행하면 발행일지에 자동으로 기록됩니다.
크롬에서 해당 매체에 미리 로그인해 두세요. 크롬에서만 동작합니다. 엣지, 사파리, 파이어폭스에서는 자동 발행이 되지 않습니다. 이 앱은 아이디와 비밀번호를 수집하지 않습니다.

언제 올릴까요

어떻게 올라가나

로그인해 둔 크롬 창을 대신 조작해 본문을 채우고 게시 버튼까지 누릅니다. 내 PC에서는 네 매체 모두 자동으로 올라갑니다. 나중에 웹사이트로 옮기면 브런치만 손으로 올려야 합니다.
